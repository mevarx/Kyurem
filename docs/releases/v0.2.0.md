# Kyurem v0.2.0

Kyurem v0.2.0 brings a redesigned management dashboard for inspecting agent traffic, tasks, costs, policy decisions and gateway health.

- Responsive light and dark dashboard with keyboard navigation, searchable task payloads and trace inspection.
- Agent verification indicators distinguish verified, unverified, unsigned and unchecked cards.
- Graph detail requests show loading and retryable errors; task pagination recovers when filters or live data change.
- Gateway connection and authentication errors provide actionable guidance while Settings remains available.
- Policy and trust views expose the gateway's read-only decision history and authorization matrix.

The root-cause indication is heuristic, policy review acknowledgements are local to the dashboard, and cost data depends on agent-reported usage. See the README and milestone documentation for setup and remaining limitations.
